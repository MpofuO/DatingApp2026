# DatingApp2026

A full-stack dating application developed during an advanced internet programming module in the honours programme. The project explores practical web development concepts, including user interaction, profile management, data handling, and application design in a modern development environment.

## Overview

This project focuses on building a functional dating application with a practical, user-facing interface and a structured backend. It was created to strengthen full-stack development skills through a realistic and hands-on workflow.

## Features

- User registration and authentication
- Profile creation and management
- Matching or interaction flow
- Messaging or connection functionality
- Responsive interface
- Database-backed application logic

## Tech Stack

This project was built using a full-stack web architecture, combining a frontend interface with a backend application and a database for persistent data storage.

Examples of technologies commonly used in this type of project include:
- ASP.NET Core / C#
- HTML, CSS, and JavaScript
- SQL or another relational database
- Entity Framework
- ASP.NET Identity or custom authentication

## Project Goals

The main goal of this project was to apply modern web development practices in a realistic application scenario while strengthening understanding of:
- application architecture
- user experience design
- database integration
- backend logic
- full-stack development workflows

## Notes

This project was developed as part of an advanced internet programming module in the honours programme and is intended primarily for learning, portfolio, and academic demonstration purposes.
